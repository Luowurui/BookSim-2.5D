# 2.5D BookSim 超详细开发周期

以《2.5D BookSim 仿真器需求说明》与《2.5D BookSim 架构规划》为基线，
本计划给出可执行的里程碑、交付物、接口检查点与验证步骤，覆盖配置、子网、路由、握手、时钟、诊断和性能优化全链路。

## 里程碑总览

| 序号 | 目标 | 关键产出 | 依赖 | 完成判据 |
| --- | --- | --- | --- | --- |
| M1 | 配置扩展与装配器落地 | `Config2_5D`、`FabricBuilder`、示例配置 | 无 | 可解析 2.5D 配置并生成单芯粒退化网络，回归与原 BookSim 等价 |
| M2 | 子网实例化与端口扩展 | `ChipletNetwork`、`InterposerNetwork`、4:1 `bridge_port` | M1 | 能生成多芯粒 + 中介层网络拓扑，端口正确暴露 |
| M3 | 组合式路由与映射 | `MappingTable`、`SegmentedRouter`、出口/入口策略插件 | M2 | 三段式路由可达性验证通过，头 flit 携带跨网提示 |
| M4 | 跨域握手与时钟 | `CDCChannel`、`HandshakeLink`、`ClockDistributor` | M2 | 异步链路传输正确，支持频率比配置，端到端延迟符合预期 |
| M5 | 死锁检测与诊断 | `VCGraph`、`CycleDetector`、`Diagnostics` | M3/M4 | 可检测跨子网 VC 环路并触发告警/恢复策略，指标采集完整 |
| M6 | 性能优化与可视化 | 采样/日志接口、可视化钩子、基准报告 | M5 | 典型规模下性能 ≤ 2× 2D 基线，生成延迟/吞吐/握手开销报告 |

## 迭代详情

### M1：配置扩展与装配器
- **目标**：允许通过配置描述芯粒列表、拓扑、映射、链路/频率/握手参数；装配器自动实例化各子网与互连。
- **任务拆分**：
  1. 扩展配置解析（如 `src/config.cpp` 或等效模块）新增 2.5D 段落：芯粒 ID、尺寸、频率、VC/缓冲、映射表路径、跨网链路延迟/同步级数。
  2. 新建 `Config2_5D` 数据结构，封装从原始配置到内部描述的转换，提供默认值与退化到 2D 的兼容路径。
  3. 实现 `FabricBuilder`：根据配置批量创建 `ChipletNetwork`/`InterposerNetwork` 对象与跨网链路占位符。
  4. 添加最小示例配置（单芯粒退化场景、双芯粒跨网场景）。
- **验证**：
  - 单芯粒退化模式运行原有 2D 基准，结果与当前 BookSim 对齐。
  - 配置解析单元测试：必填/选填字段、默认值回退、错误提示。

### M2：子网实例化与端口扩展
- **目标**：将每个芯粒和中介层建模为独立子网，支持集中式网格与 4:1 互连端口。
- **任务拆分**：
  1. 提取子网抽象基类（如 `Network` 扩展）形成 `ChipletNetwork`、`InterposerNetwork`，保留 BookSim RC/VA/SA/Switch 管线。
  2. 在中介层路由器增加 4 个 I/O 端口用于芯粒互连（`bridge_port`），芯粒侧暴露对称端口。
  3. 为端口参数提供独立配置（缓冲深度、VC 数、带宽），并与本地终端 `local_port` 区分。
  4. 在 `FabricBuilder` 中绑定端口与跨网链路占位符，支持多芯粒拓扑生成。
- **验证**：
  - 拓扑生成测试：核对端口数量、坐标映射与链路连通性。
  - 与 M1 配置示例结合，检查多芯粒 + 中介层场景能正常初始化。

### M3：组合式路由与映射机制
- **目标**：实现三段式路由与映射表，避免全局路由依赖。
- **任务拆分**：
  1. 设计地址拆解：全局地址 → (芯粒 ID, 芯粒内坐标)，在头 flit 携带目标芯粒和入口提示字段。
  2. `MappingTable` 支持静态配置/可热加载，提供出口选择与入口落点查询接口。
  3. `SegmentedRouter`：源段按本地算法选出口 `bridge_port`；中介层按芯粒 ID 路由；目的段按提示/查表送达终端。
  4. 策略插件接口：出口/入口选择可替换（静态表、哈希、脚本策略）。
- **验证**：
  - 可达性测试：跨芯粒端到端路径存在，分段路由能正确拼接。
  - 单元测试：映射表查找、头 flit 提示保留、策略插件覆盖。
  - 与 M2 拓扑结合，运行小规模流量，验证不会访问未配置端口。

### M4：跨域握手与时钟体系
- **目标**：支持不同频率子网的跨时钟域通信，显式模拟握手与同步延迟。
- **任务拆分**：
  1. `ClockDistributor`：计算最小 tick，按频率产生本地时钟事件并驱动各子网管线。
  2. `HandshakeLink`/`CDCChannel`：基于 ready/valid 或 req/ack，实现打拍、同步器级数、链路传输延迟；支持阻塞/非阻塞/超时模式。
  3. 在跨网 `bridge_port` 绑定握手通道，维持 flit/credit 在未确认前保留。
  4. 统计接口：记录握手次数、同步延迟、时钟偏移日志。
- **验证**：
  - 时钟对齐测试：验证不同频率下 tick 驱动顺序正确、事件不丢失。
  - 链路延迟测试：注入固定延迟，核对端到端延迟与期望一致。
  - 异步压力测试：高负载下无数据丢失或乱序。

### M5：死锁检测与诊断
- **目标**：覆盖芯粒与中介层 VC 的通道循环依赖检测与告警/恢复。
- **任务拆分**：
  1. `VCGraph`：跨子网追踪 VC/握手通道的占用关系，构建等待图。
  2. `CycleDetector`：周期检测算法（如 Tarjan/DFS），支持可配置检测周期与告警阈值。
  3. `Diagnostics`：收集跨芯粒延迟、握手次数、同步器开销、死锁事件；提供 JSON/CSV 导出与回调接口。
  4. 恢复策略插件：超时重路由、包丢弃、专用解锁 VC，可按策略选择。
- **验证**：
  - 人工注入阻塞场景，确认能检测并触发恢复策略。
  - 长时间运行下资源释放正确，无误报或漏报显著上升。

### M6：性能优化与可视化
- **目标**：在保持准确度的前提下，将仿真开销控制在基线 2× 以内，并输出可视化数据。
- **任务拆分**：
  1. 性能基准：定义典型规模（如 4 芯粒、每网格 4×4、VC/缓冲与 2D 一致），记录纯 2D 与 2.5D 的吞吐/延迟/运行时间。
  2. 优化策略：事件批处理、可配置采样频率、可选关闭重型诊断；跨域链路可选择近似模型。
  3. 可视化钩子：导出握手时间线、时钟偏移、VC 占用、死锁告警，提供 JSON/CSV/可选脚本生成图表。
  4. 文档与示例：补充配置模板、运行脚本、结果解读指南。
- **验证**：
  - 基准运行报告：确认性能目标（≤2× 基线）达成或给出优化方案。
  - 可视化输出检查：数据格式正确，可被外部工具解析。

## 持续交付与质量控制
- **测试体系**：
  - 单元：配置解析、映射表、策略插件、握手通道、时钟分发、等待图/检测器。
  - 集成：跨芯粒流量、异步链路压力、死锁注入/恢复、性能基准。
  - 回归：单芯粒退化 2D 与原 BookSim 结果比对。
- **代码规范**：保持模块化，避免将子网/时钟/握手逻辑耦合到核心管线；新增接口需文档化，默认退化为 2D 行为。
- **配置兼容性**：所有新增字段提供默认值；缺失 2.5D 段落时自动按 2D 路径执行。
- **文档同步**：每个里程碑更新用户手册/README 示例，标注新增配置项与典型用例。

## 交付检查清单（每里程碑）
- 代码：核心实现 + 必要的接口/插件示例。
- 配置：最小可运行示例（退化 2D + 代表性 2.5D）。
- 测试：自动化脚本或指令，含预期输出对比。
- 文档：更新的使用说明、架构/时序示例、限制与兼容性说明。
- 性能/稳定性：对照基线的运行时间与资源占用记录。
