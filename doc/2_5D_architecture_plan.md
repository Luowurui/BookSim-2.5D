# 2.5D BookSim 架构规划

## 设计视角
- **目标对齐**：以《2.5D BookSim 仿真器需求说明》为约束，提供可迭代的分层架构，支持独立芯粒/中介层建模、组合式路由、跨时钟域握手与死锁可视化。
- **演进路线**：尽量复用 BookSim 事件/管线模型；新增子网、映射、握手与时钟分发层为可插拔模块，便于裁剪或替换。

## 总体分层
1. **配置与装配层**：解析 2.5D 配置，实例化芯粒子网、中介层子网及跨网链路，完成映射表加载。
2. **子网抽象层**：封装单个网络实例（拓扑、路由、流控、VC/交换分配管线），对外暴露本地端口与跨网端口。
3. **组合式路由层**：实现三段式路由（源芯粒 → 中介层 → 目的芯粒），包含地址拆解、出口/入口选择策略与跨网提示封装。
4. **跨域握手与时间层**：为跨网链路提供握手协议、同步器与时钟分发，按最小 tick 驱动异步子网协同。
5. **可视化与调试层**：收集 VC 占用、握手事件、时钟偏移并进行死锁/活锁检测，提供日志与可视化接口。

## 关键组件与接口
### 1. 配置与构造
- **模块**：`Config2_5D`（扩展现有配置解析）、`FabricBuilder`（装配器）。
- **职责**：
  - 解析芯粒列表（ID、尺寸、频率）、中介层参数、映射表（全局地址 → 芯粒 ID + 局部坐标）、跨网链路属性（延迟/带宽/同步级数）。
  - 生成默认集中式网格拓扑与 4:1 互连模板，可用占位符快速生成常见 2.5D 形态。
- **交互**：向子网抽象层提供构造参数，向组合式路由层注册映射与策略插件。

### 2. 子网抽象
- **模块**：`ChipletNetwork`, `InterposerNetwork`, `SubnetPort`。
- **职责**：
  - 封装 BookSim 内部路由器/链路/VC 资源；芯粒与中介层共享核心实现但允许独立参数。
  - 在路由器上增加跨网端口（中介层侧提供额外 4 个 I/O，形成 4:1 互连）。
  - 暴露 `local_port`（接终端）与 `bridge_port`（跨网互联）接口，供握手层绑定。
- **管线复用**：继承 RC/VA/SA/Switch 的同步管线，保持事件驱动模型不变。

### 3. 组合式路由
- **模块**：`SegmentedRouter`, `MappingTable`, `EgressSelector`, `IngressSelector`。
- **路由流程**：
  1. **源段**：按局部拓扑与本地路由算法，将包送至出口 `bridge_port`；在头 flit 附带目标芯粒 ID、入口提示。
  2. **跨段**：中介层依据目标芯粒 ID 选择入口；路由算法可独立配置（XY/最短路/最小转弯/VC 分离）。
  3. **目的段**：目的芯粒入口路由器解析提示或再次查表，将包送至目的终端。
- **策略插拔**：出口/入口选择以策略接口形式存在，可基于静态映射、哈希或脚本化策略实现负载均衡。

### 4. 跨域握手与时间管理
- **模块**：`CDCChannel`（跨域通道）、`HandshakeLink`（就绪/有效或请求/应答）、`ClockDistributor`。
- **握手行为**：
  - 发送端在未获确认前保持 flit/credit；链路可配置打拍/同步器级数与传输延迟，事件化模拟跨时钟域数据/信号传播。
  - 支持阻塞/非阻塞/超时发送模式，对应 FreeRTOS 风格队列语义。
- **时钟体系**：
  - 计算全局最小 tick，`ClockDistributor` 按各子网频率产生本地时钟事件；异步链路在 tick 级调度传输和确认事件。
  - 记录频率比、相位与偏移，用于可视化与调试。

### 5. 死锁检测与可视化
- **模块**：`VCGraph`, `CycleDetector`, `Diagnostics`。
- **检测逻辑**：
  - 在芯粒与中介层路由器上追踪 VC 分配/占用，构建等待图；跨网握手链路作为资源节点纳入检测。
  - 周期检测触发告警或策略：超时重路由、丢弃包、专用解锁 VC。
- **观测接口**：导出跨芯粒延迟、握手次数、同步器开销、死锁告警日志；可选 JSON/CSV/可视化钩子。

## 数据流与控制流
- **数据流**：终端 → 芯粒子网 → 出口 `bridge_port` → 握手链路 → 中介层子网 → 入口 `bridge_port` → 握手链路 → 目的芯粒子网 → 终端。
- **控制流**：
  - 子网管线由本地时钟事件驱动；跨域链路由握手事件驱动。
  - 组合式路由在头 flit 生成跨网提示，后续 flit 继承；死锁检测与诊断异步采样。

## 演进与交付里程碑
1. **配置扩展与装配器**：实现 `Config2_5D`/`FabricBuilder`，支持单芯粒退化模式回归测试。
2. **子网与端口扩展**：完成芯粒/中介层网络实例化、4:1 互连端口与桥接接口。
3. **组合式路由实现**：映射表、出口/入口策略与跨网提示封装；验证三段式路径正确性。
4. **握手与时钟体系**：`CDCChannel` + `ClockDistributor`，支持频率比与链路延迟配置；完成跨域传输验证。
5. **死锁检测与诊断**：等待图/周期检测与告警；引入可配置恢复策略与统计接口。
6. **性能与可视化**：基准用例、开销评估、可视化输出，确保 ≤2× 基线性能目标。

## 兼容性与可扩展性
- 保持与现有 BookSim 配置/事件模型兼容，默认配置自动退化为 2D 行为。
- 插件接口（路由、映射、握手、死锁恢复、观测回调）支持外部扩展，避免核心代码分叉。
- 文档与示例需同步更新：配置样例、接口说明、典型 2.5D 拓扑与时序示例。
